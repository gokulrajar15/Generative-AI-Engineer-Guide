# 15. Understanding LLM Inference Metrics

Key performance indicators for LLM deployment.

---

## Core Metrics

### Latency
- **TTFT** (Time to First Token): How quickly the first token appears
- **TPOT** (Time Per Output Token): Generation speed for each token
- **Total latency**: End-to-end response time

### Throughput
- **Requests per second**: How many requests the system can handle
- **Tokens per second**: Generation speed across all requests

### Memory Usage
- **GPU memory**: VRAM consumption
- **CPU memory**: RAM usage for inference

### Cost Efficiency
- **Cost per token**: Operational cost
- **Cost per request**: Total expense per API call
