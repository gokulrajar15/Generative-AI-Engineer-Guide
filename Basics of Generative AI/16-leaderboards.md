# 16. LLM Leaderboards

Popular leaderboards for tracking model performance.

---

## Major Leaderboards

### Artificial Analysis
Comprehensive model comparisons across providers
🔗 [artificialanalysis.ai](https://artificialanalysis.ai)

### Vellum
Enterprise-focused evaluations
🔗 [vellum.ai/llm-leaderboard](https://www.vellum.ai/llm-leaderboard)

### Scale.com
Standardized benchmarks and evaluations
🔗 [scale.com/leaderboard](https://scale.com/leaderboard)

### Hugging Face
Open-source model rankings
🔗 [huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard](https://huggingface.co/spaces/HuggingFaceH4/open_llm_leaderboard)

### Live Bench
Real-time performance tracking
🔗 [livebench.ai](https://livebench.ai)
